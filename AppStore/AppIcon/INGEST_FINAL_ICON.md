# Final AppIcon Intake

Use one approved, production-grade **1024×1024 PNG** source named `source-1024.png`. Keep it unique to this product's visual identity. Do not use screenshots, SF Symbols as the complete logo, copied competitor marks, text-heavy artwork, or synthetic placeholders as final store art.

Run `python3 Scripts/build_phase_n_appicon.py` to generate the macOS asset slots. Final compiled-asset inspection still happens in Xcode on Mac.
