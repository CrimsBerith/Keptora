## 5. Apple İnceleme Ekibi Notları (App Review Information)

*App Store Connect → Version → App Review Information → Notes*

**Review Notes (Kopyalayıp Yapıştırın):**
```
Keptora is a local-first photo duplicate cleaner for macOS.

Key Review Information:
1. All file scanning, SHA-256 hashing, and similarity processing happen 100% locally on device. No media or analytics are ever uploaded to any server.
2. Apple Photos cleanup moves files to the user's "Recently Deleted" album via standard PhotoKit APIs; it never permanently deletes user media.
3. Folder cleanup moves duplicate files to a local ".Keptora Quarantine" folder on the same volume with a signed manifest and full 1-click restore capabilities.
4. Export Compliance: Uses standard platform CommonCrypto SHA-256. (ITSAppUsesNonExemptEncryption = false).

Demo Instructions:
- Open Keptora.
- Select a photo folder or Apple Photos library.
- Click "Scan".
- Review exact duplicates; notice the keeper is locked and protected.
- Review Safety Plan and commit to test local quarantine.

Contact: support@alfagolab.com
```

## 6. Xcode'dan App Store Connect'e Yükleme (Adım Adım)

1. **Xcode'u Açın**: `Keptora.xcodeproj` projesini Xcode ile açın.
2. **Target Seçin**: `Keptora` target'ını seçin.
3. **Signing Kontrolü**:
   - `Signing & Capabilities` sekmesinde Team olarak `KAGAN KARTAL BABAHAN (ZSRUTGX74S)` seçili olduğunu teyit edin.
   - Bundle Identifier: `com.alfagolab.keptora`.
4. **Archive Alın**:
   - Üst menüden hedefi `Any Mac (Apple Silicon, Intel)` yapın.
   - `Product` → `Archive` seçeneğine tıklayın.
5. **Organizer Açılacak**:
   - Oluşan `1.0.0 (182)` sürümünü seçin.
   - Sağdaki mavi **"Distribute App"** butonuna tıklayın.
   - **"Custom"** veya **"App Store Connect"** seçin → **"Upload"** deyin.
   - Otomatik imzalama (Automatically manage signing) ile ilerleyin.
   - **Upload** butonuna basarak build'i doğrudan App Store Connect'e gönderin!
6. **App Store Connect'te Seçin**:
   - Yaklaşık 10-15 dakika içinde build işlenir (Processed).
   - App Store Connect sayfanızda Version 1.0.0 altına bu build'i seçip ekleyin.
   - IAP'ı (`com.keptora.app.pro.lifetime`) bu sürüme bağlayın.
   - Yukarıdaki metinleri yapıştırıp **"Submit for Review"** butonuna basın!
