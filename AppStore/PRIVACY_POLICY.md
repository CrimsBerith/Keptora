## 1. Local-first operation

Keptora analyzes the photos, videos and folders a user chooses, on the user’s own iPhone or Mac. The app does not require an account and does not upload photos, videos, file names, fingerprints, thumbnails, location or capture details, selections, cleanup decisions or diagnostic information to the developer.

## 2. Information processed on the device

To provide its features, Keptora may process and store locally:

- Items in Apple Photos that the user allows Keptora to access (all photos or only selected photos).
- Folders and files the user chooses, and the security-scoped bookmarks needed to reopen them.
- File names, sizes, dates, media type, album membership, favorite status and similar metadata.
- Capture time, location and burst information, used only to group related shots.
- Exact fingerprints (SHA-256) that prove byte-for-byte copies.
- On-device visual similarity features used to suggest similar photos.
- Thumbnail and fingerprint caches, which the user can clear in Settings.
- The user’s current selection, protected items, items to keep, and cleanup history.
- Preferences such as the app language, the selected sources, onboarding completion and the count of free review decisions.

This information remains on the user’s device.

## 3. Photos and folder permissions

Keptora asks for Photos access only when the user chooses to open Photos, and accesses folders only after the user selects them. iOS and macOS control these permissions, and users can review or revoke them in Settings (iPhone) or System Settings (Mac). Revoking access can prevent scans, cleanup or restoration until access is granted again.

Keptora does not download iCloud originals unless the user starts a scan that includes cloud originals. Those downloads come from Apple’s iCloud service to the user’s device; nothing is sent to the developer.

## 4. Removal and recovery

Keptora removes only the items the user selects and confirms on the final review screen.

- **Apple Photos items** are removed through Apple’s system confirmation and move to Recently Deleted, where they can be recovered for up to 30 days unless the user deletes them sooner. With iCloud Photos, the change syncs to the user’s other devices.
- **Folder files** move to a recovery folder on the same storage and are recorded in Keptora’s History so they can be restored. This does not free disk space until the user empties the recovery folder.

Users should keep independent backups of irreplaceable files.

## 5. Purchases

A one-time Keptora Pro unlock can be purchased through Apple’s App Store. Apple processes payment and account information under Apple’s terms and privacy policy. Keptora reads verified StoreKit entitlement information to determine whether Pro is unlocked. The developer does not receive payment-card information.

## 6. Diagnostics and support

On Mac, a user can export or copy a diagnostic JSON file from Settings. It contains counts and app state (for example, how many items were analyzed and which analysis stages finished). It does not contain images, file names, paths or fingerprints. The file is never sent automatically. If a user chooses to share it with support, the developer uses it only to investigate the reported issue and keeps it only as long as reasonably necessary for support, legal or security purposes.

## 7. Analytics, advertising and tracking

Keptora contains no advertising SDK, third-party analytics SDK, account system or cross-app tracking. This policy and the App Store privacy label will be updated before any such functionality is introduced.

## 8. Data retention and deletion

Local Keptora data remains on the user’s device until the user clears it in the app, removes a history record after restoring its files, or deletes the app. Files in a recovery folder should not be deleted manually before the user has restored anything they want to keep. Support data voluntarily sent to the developer is handled as described in Section 6.

## 9. Security

Keptora uses the iOS and macOS app sandbox, system-controlled Photos and file permissions, and conservative cleanup rules: exact copies require byte-level proof, items marked to keep or protected are never selected automatically, and every removal needs the user’s final confirmation. No software can guarantee absolute security or prevent every hardware, file-system or user error.

## 10. Children

Keptora is a general-purpose utility and is not directed to children. It does not knowingly collect personal information from children.

## 11. International users

Processing stays on the user’s device. If a user contacts support, their message and attachments may be processed in the countries where the developer or its service providers operate, subject to applicable law.
