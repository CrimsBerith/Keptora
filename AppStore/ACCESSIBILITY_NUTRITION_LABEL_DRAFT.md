# Keptora — Accessibility Nutrition Label Draft

Candidate features to validate on the final Mac build:
- VoiceOver: source identifiers/labels present; verify all common tasks end-to-end.
- Voice Control: verify visible control names can be invoked.
- Larger Text: verify primary workflows at enlarged text without clipping.
- Differentiate Without Color: verify status is not color-only.
- Reduce Motion: source hardening present where motion exists; verify runtime behavior.
- Sufficient Contrast: verify light/dark/high-contrast states on real macOS.

Only claim a label after the final signed build meets Apple’s evaluation criteria for common tasks.
