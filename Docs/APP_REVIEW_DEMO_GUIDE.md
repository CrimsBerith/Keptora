# Cullora App Review Demo Guide

## Fastest deterministic review path

1. Launch Cullora and complete the three-page safety tour.
2. On Library Health, choose **Choose Folder** and select the prepared review corpus.
3. Cullora generates synthetic images locally and runs the real incremental scanner.
4. Open Review Studio.
5. Use `⌘]` to move between groups and `⌥→` to move focus between photos.
6. Use `⌘2` to add a focused non-keeper to the reversible Safety Plan, or use **Plan Exact Extras**.
7. Open Review Insights to see local progress and the saved session checkpoint.
8. Prepare the Safety Plan; verify that the protected keeper is absent from operations.
9. Commit quarantine only in a StoreKit-unlocked test account, then restore from History.

## What the reviewer should observe

- The sample library is generated by the app; no network or account is used.
- Exact sets are SHA-256 verified.
- Similar photos can be inspected but are never automatically added to cleanup.
- Review progress survives navigation and app inactivity.
- Quarantine is reversible and no permanent-delete command exists.
