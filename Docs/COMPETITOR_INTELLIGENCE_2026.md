# Cullora Competitor Intelligence — 2026-08-04

## Purpose

This register expands the earlier market research with direct Mac duplicate cleaners, Photos-library managers, professional culling products, editing-suite incumbents, and mobile-adjacent workflow signals. It is not a claim that every product is a direct substitute. Each row is tagged by segment so that mobile swipe cleaners are not compared as if they had the same file, sandbox, RAW, sidecar, external-volume, and recovery responsibilities as Cullora.

## Product conclusion

Cullora should not compete by promising the broadest AI cleaner. The defensible position remains:

> **Exact cleanup is provable and reversible; similar-photo evidence is explainable and review-only.**

The research supports four immediate product decisions:

1. Users need filters, queue state, sorting, and visible progress when libraries become large.
2. Batch actions are valuable only when the proof boundary is obvious. Cullora therefore allows batch planning only for SHA-256 exact groups and always excludes the keeper.
3. Keeper selection must be explainable and overridable.
4. Savings/history should be visible without encouraging automatic permanent deletion.

## Immediate adoption ledger — implemented in Phase 5L

- Review queue filters: All, Unreviewed, In Progress, Planned, Reviewed.
- Search across file names and paths.
- Sort by recoverable storage, copy count, or name.
- Exact-group progress and queue-state badges.
- Exact-only `Plan Exact Extras` batch action.
- Exact-only `Skip Extras` batch action.
- Atomic batch entitlement check so a free user never receives a partially applied group action.
- Review Insights page with potential/planned recovery and pipeline state.
- Keeper explanation and Finder reveal.

## Deliberately deferred

- Photos-library mutation and multi-library merge.
- Background folder monitoring.
- Face/eye scoring and best-shot selection.
- XMP stars, color labels, Lightroom/Capture One handoff.
- Date-range scan presets and screenshot/text smart collections.
- Semantic search and face indexing.

These are credible later features, but each expands privacy, accuracy, performance, or App Review risk and requires real-photo calibration plus Mac QA.

## Rejected for V1

- One-click deletion of similar photos.
- Automatic permanent deletion from Apple Photos.
- Cloud upload or account requirement for core processing.
- Subscription-only access.
- Video compression, editing, retouching, DAM, gallery delivery, or camera ingest expansion.
